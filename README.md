Spatial Audits — Sizes, Spaces, Depths, Environments, and Consistency — Forced Audit Checklist

General scope. These audits apply to any scene. No scene specifics. No named individuals. Every question is sourced from the standing rules. Nothing here is invented.

The forcing rule

• The AI runs every question in this document against every tych before delivering output.
• Every question must pass. One failure means the scene fails.
• When a question fails, fix the scene. Never weaken the question.
• No skipping. No leniency. No redos counted as passes.
1. Accurate sizes in space

• Does every size read accurately against the 1:1 world around it?
• Does the stated size match the depicted size in the space?
• Is there any wrong distance?
• Is there any wrong depth?
• Is there any wrong focal point?
• Is any measurement exaggerated?
• Is any size inflated?
• Is any distance stretched?
• Is any weight overstated?
• Are all items, objects, furniture, and furnishings at constant 1:1 size?
• Is there true scale throughout the space?
2. Depth layers and focal points

• Does the scene have a foreground?
• Does the scene have a midground?
• Does the scene have a background?
• Is there honest occlusion between the layers?
• Does the scene have real depth from front to back?
• Does anything float in empty space?
• Are there clear focal points?
• Is there honest perspective?
3. No flatness, no backdrops

• Is this a flat composition?
• Is the environment used as a mere backdrop?
• Is any surface used as a mere backdrop?
• Is there any digital render or art look?
• Do real environments carry depth, focal points, and honest perspective — never flatness?
4. Plausible locations for humans

• Does the human genuinely occupy the indicated three-dimensional location?
• Do body orientation, visible surfaces, foreshortening, occlusion, contact points, and distance from the camera agree with the surrounding geometry?
• Is the human placed where a human could really be at that exact size?
• Is everything the human lifts physically possible at the exact stated size and location?
• Is everything the human reaches physically possible at the exact stated size and location?
• Is everything the human touches physically possible at the exact stated size and location?
5. Plausible locations for items and objects

• Is every item where it would really be?
• Is every object true-sized and plausible?
• Do objects at equivalent depths obey the same perspective behavior?
• Where a human touches an object, is there mutually consistent perspective, depth, occlusion, contact geometry, and scale?
• Where a human stands on, sits on, or holds an object, is there mutually consistent perspective, depth, occlusion, contact geometry, and scale?
6. Real life environments

• Is this real life in a real environment?
• Is the environment specific?
• Is the environment tangible?
• Is the environment spatially coherent?
• Is it blank?
• Is it generic?
• Is it a vague backdrop?
• Is the environment non-surreal?
• Is there any exaggerated interior?
• Is there any exaggerated exterior?
• Is this ordinary 1:1 reality built for normal-sized people?
• Is the 1:1 world defined generally, with no scene specifics baked into the definition?
7. Consistency from tych to tych

• Does the same room continue across tychs?
• Does the same time of day continue across tychs?
• Does the same weather continue across tychs?
• Does the lighting direction stay consistent across tychs?
• Do environments, settings, and furnishings stay consistent?
• Is every human's position tracked consistently from tych to tych?
• Is there any random teleporting?
• Did the world quietly reset between any two panels?
8. Consistency from scene to scene

• When a scene continues a previous one, does the environment persist?
• Is there consistent continuity from image to image?
• Did anything in the world change without a depicted cause?
• Is there any silent reset between scenes?
Final gate

• Run every question above against every tych.
• Every question passes, or the scene does not ship.
• When a question fails, fix the scene. Never weaken the question.
